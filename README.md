# The World — 18 November 2026

[![build](https://make.fun/badge/news-image-20261118.svg)](https://make.fun/bounty/news-image-20261118)

A single-page world news front page with 31 briefs across six sections and a labeled world locator.

Run **bash render.sh** to create **/output/entry.png**. Rendering uses Chromium first and the included Pillow renderer if Chromium is unavailable. Run **node main.ts** to copy a prepared **entry.png** into the output directory.

The image is designed as a 1024 × 1024 PNG. The project is MIT licensed.
